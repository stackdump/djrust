# Contributing

Thanks for your interest in djrust.

**Bug reports and feature requests are welcome.** Open an issue at
<https://github.com/stackdump/djrust/issues>. For a bug, say which djrust version and which
features you built with, the target (browser, Android, iOS, desktop), and the smallest input that
shows it: a track spec (`genre:seed[:structure]`) or a share CID is usually enough, since the
engine is deterministic and the same input renders the same samples.

**Outside code and pull requests are not accepted.** djrust is developed by one person, and every
change is written in-house. Pull requests will be closed without review, however good. If you have
a fix in mind, describe it in an issue instead; that is just as useful.

Security problems: please do not file a public issue; open a private security advisory on the
repository instead.
